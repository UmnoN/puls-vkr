# ПУЛЬС: прогнозирование вероятности закрытия сделки и приоритизация клиентов

Выпускная квалификационная работа по программе «Data Science PRO» (ЦДО МГТУ им. Н.Э. Баумана).

Проект решает задачу приоритизации клиентов в системе корпоративных продаж НПФ: предсказывает вероятность закрытия сделки и рассчитывает приоритет обработки на основе исторических данных CRM.

## Данные

- 764 сделки (571 новых + 193 действующих клиентов) и 399 лидов, выгрузка из Creatio.
- Обучение модели проводится только на resolved-подвыборке (274 сделки с определённым исходом), остальные сделки используются исключительно для inference.
- Стадия сделки и производные от неё показатели не используются как признаки модели — во избежание утечки целевой переменной.

## Модели

Лучшая модель для сделок — Gradient Boosting (ROC-AUC 0.854), для лидов — логистическая регрессия. Сравнение всех обученных моделей — в `data/итоговое_сравнение_моделей.csv` и `data/сравнение_моделей_лидов.csv`.

## Структура репозитория

```
├── notebooks/       — Jupyter-ноутбук с полным пайплайном (EDA, обучение, оценка моделей)
│   └── src/          — вспомогательные модули (обработка признаков, обучение отдельных моделей)
├── service/          — рабочий сервис на Streamlit (веб-форма для получения прогноза)
│   ├── core/          — бизнес-логика, работа с БД (SQLAlchemy, Bronze/Silver)
│   └── services/      — сервисы загрузки данных и скоринга
├── docs/             — схема БД, презентация (PowerPoint + PDF), иллюстрации
└── data/             — исходные и обработанные датасеты (CSV)
```

## Архитектура сервиса

Хранение данных реализовано по двухслойной схеме Bronze/Silver, доступ через SQLAlchemy (переключение SQLite ↔ PostgreSQL без изменения кода). Каждый сервис логирует свою работу в единую таблицу `service_logs`.

## Запуск сервиса

```bash
cd service
pip install -r requirements.txt
streamlit run streamlit_app.py
```
